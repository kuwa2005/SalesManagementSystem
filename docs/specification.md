## 1. システム概要

### 1.1 システムの目的

得意先・商品などのマスタを基盤に、売上伝票、請求書、入金、売掛残高を一元管理し、販売実績・粗利益・前年対比などの帳票を出力するWeb型販売管理システム。

### 1.2 対象業務

| 業務領域 | 対象 |
|----------|------|
| 事前設定 | 会社基本情報、部門、担当者、入金区分、摘要、得意先、商品カテゴリー、商品 |
| 売上管理 | 売上伝票の登録・訂正・複写・削除・赤伝、各種伝票出力 |
| 請求管理 | 締め請求、都度請求、請求書作成・再出力・締解除 |
| 入金管理 | 入金登録・訂正・削除、請求書紐付、入金一覧、領収書 |
| 照会・帳票 | 得意先元帳、売掛残高、売上明細・日報・月報、分析レポート |
| 外部連携 | 経理向け会計CSV出力 |
| 運用管理 | 年度選択、年次繰越、ユーザ管理、機能権限管理 |

### 1.3 動作環境

| 項目 | 仕様 |
|------|------|
| 提供形態 | インターネット接続を前提とするWebアプリケーション |
| ブラウザ | Google Chrome、Microsoft Edge、Firefox、Safari |
| 画面解像度 | 1024×768以上、1920×1080推奨 |
| 対応端末 | PC、Android、iPhone、iPad |

## 3. 認証・権限

### 3.1 認証フロー

1. 契約者ID、ログインID、パスワードを入力してログイン
2. 利用年度を選択
3. 選択年度とログインユーザをセッションに保持し、トップメニューを表示

### 3.2 ユーザ種別

| 種別 | 権限 |
|------|------|
| 管理者 | 全メニュー実行権限、利用者追加、権限付与、年次繰越 |
| 利用者 | 管理者により追加、付与されたカテゴリー・機能のみ利用可能 |

### 3.3 権限モデル

| 表示 | 意味 |
|------|------|
| ● | カテゴリー配下の全機能を許可 |
| ○ | カテゴリー配下の一部機能を許可 |
| 空欄 | カテゴリーを不許可 |

## 4. マスタ仕様

### 4.1 マスタ登録順序

| 段階 | 処理 |
|------|------|
| 1 | 基本情報（必須） |
| 2 | 部門・担当者・入金区分・摘要（任意） |
| 3 | 得意先（必須） |
| 4 | 商品カテゴリー（任意） |
| 5 | 商品（必須） |

### 4.2 業務ルール

| ID | ルール | システム動作 |
|----|--------|-------------|
| MST-R01 | コード不変 | 部門・担当者・入金区分・摘要・得意先・商品コードは登録後変更不可 |
| MST-R02 | 参照済み削除禁止 | 伝票等で使用中のマスタは削除不可 |
| MST-R03 | CSV上書き | 同一コードが取込CSVに存在する場合、内容で上書き |
| MST-R04 | CSV全件停止 | エラー時は取込処理を停止 |

### 4.3 得意先税処理

| 税処理 | 計算タイミング | 単価の基準 |
|--------|----------------|------------|
| 外税/伝票計 | 売上伝票単位 | 税抜単価 |
| 外税/請求時 | 請求書単位 | 税抜単価 |
| 内税/伝票計 | 売上伝票単位 | 税込単価 |
| 内税/請求時 | 請求書単位 | 税込単価 |
| 免税 | 計算なし | 登録単価 |
| 外税/手入力 | 明細手入力 | 任意 |

## 5. 売上伝票仕様

### 5.1 登録フロー

1. 売上日付、部門、当社担当者、請求先、納品先、税処理、単価種別を入力
2. 明細行ごとに内訳区分、商品、ケースまたは数量、単価、備考を入力
3. 金額、消費税、粗利益、粗利率、伝票合計を自動計算
4. 登録時に伝票番号を確定

### 5.2 内訳区分

| 区分 | 入力・計算仕様 |
|------|----------------|
| 通常 | 商品を指定し、ケースまたは数量から金額を自動計算 |
| 値引き | 商品を指定し、金額にマイナス値を入力 |
| 返品 | 商品を指定。数量入力時はマイナス表示 |
| 消費税 | 税額を手入力 |
| 摘要 | 商品名欄のみコメント入力可 |

### 5.3 計算仕様

| ID | 業務ルール | システム動作 |
|----|------------|-------------|
| SAL-C01 | ケース数量 | 入数とケースが入力されている場合、数量 = 入数 × ケース |
| SAL-C02 | 売上金額 | 金額 = 数量 × 単価（金額端数処理を適用） |
| SAL-C03 | 返品 | 返品行は数量・金額を負数として集計 |
| SAL-C04 | 値引き | 値引き行の金額は負数 |
| SAL-C05 | 税率 | 売上日付と商品課税区分・軽減税率区分から適用税率を決定 |

### 5.4 登録後操作

| 操作 | 未請求 | 請求締済 |
|------|--------|----------|
| 訂正 | 可 | 不可 |
| 削除 | 可 | 不可 |
| 複写 | 可 | 可 |
| 赤伝 | 可 | 可 |

## 6. 請求仕様

### 6.1 請求方式

| 方式 | 用途 | 請求書生成タイミング |
|------|------|----------------------|
| 締め請求 | 期間内売上をまとめて請求 | 請求業務で締年月日を指定して作成 |
| 都度請求 | 売上ごとに請求 | 売上伝票出力または同時出力時 |

### 6.2 請求書計算

| 項目 | 計算式 |
|------|--------|
| 前回御請求額 | 前回の請求金額 |
| 御入金額 | 前回請求締後から今回請求締までの入金額 |
| 繰越金額 | 前回御請求額 - 御入金額 |
| 今回御買上額 | 今回締対象期間の税抜または内税売上額 |
| 消費税 | 得意先税処理に従い算出 |
| 御買上合計 | 今回御買上額 + 消費税 |
| 今回御請求額 | 繰越金額 + 御買上合計 |

### 6.3 請求締状態遷移

| 状態 | 登録・変更 | 請求書出力 | 締解除 |
|------|------------|------------|--------|
| 未請求 | 可 | 締め請求作成対象 | - |
| 請求締済 | 不可 | 再出力可 | 可 |
| 入金紐付済 | 不可 | 再出力可 | 不可 |

### 6.4 締解除ルール

| ID | ルール |
|----|--------|
| INV-R01 | 指定した請求書より後の日付の請求締済み請求書も同時に解除 |
| INV-R02 | 締解除後は請求日が古い請求書から順に再作成 |
| INV-R03 | 請求書に入金伝票が紐付いている場合、先に入金入力で紐付を解除 |

## 7. 入金仕様

### 7.1 入金入力項目

| 項目 | 型・桁数 | 必須 | 仕様 |
|------|----------|------|------|
| 伝票番号 | 文字 10 | 条件 | 自動付番時は省略可 |
| 入金日 | 日付 | ○ | yyyy/mm/dd |
| 請求先 | コード 14 | ○ | 得意先マスタ参照 |
| 入金区分 | 参照 | ○ | 入金区分マスタから選択 |
| 入金金額 | 数値 9 | ○ | 返金はマイナス符号 |

### 7.2 請求書紐付

- 入金額と同額の請求書1枚のみ紐付可
- 領収書出力には請求書紐付が必須

## 8. 帳票・分析仕様

### 8.1 帳票一覧

| 帳票 | 目的 | 出力形式 |
|------|------|----------|
| 得意先元帳 | 得意先別の売掛取引 | PDF |
| 売掛残高一覧 | 得意先別売掛残高 | CSV/PDF |
| 売上明細表 | 売上明細 | CSV/PDF |
| 売上日報 | 日次集計 | CSV/PDF |
| 売上月報 | 月次集計 | CSV/PDF |
| 売上推移表 | 月別実績と昨年対比 | CSV/PDF |
| 売上順位表 | 順位・構成比・累計 | CSV/PDF |
| 売上伸び率順位表 | 前年差・伸び率 | CSV/PDF |
| 売上分析表 | 純売上・数量・粗利益 | CSV/PDF |

### 8.2 集計指標

| 指標 | 仕様 |
|------|------|
| 純売上金額 | 通常売上 - 値引き - 返品 |
| 粗利益 | 税抜売上 - 原価 |
| 粗利率 | 粗利益 ÷ 税抜売上 × 100 |
| 構成比 | 対象行の集計値 ÷ 全体集計値 × 100 |
| 昨年対比 | 今年集計値 ÷ 昨年集計値 × 100 |

## 9. 年次繰越仕様

### 9.1 初回繰越

- 翌年度を年度選択画面へ追加
- 前年のマスタデータを翌年度用として新規生成
- 得意先マスタの期首売掛残高に前年末売掛残高を設定
- 一度実行した年次繰越は取り消せない

### 9.2 再実行

| 再実行種別 | 処理 |
|------------|------|
| 売掛残高のみ繰越 | 翌年度期首残高のみ更新 |
| 売掛残高とマスタを繰越 | 残高を更新し、前年マスタを上書き・追加 |

## 10. CSV取込仕様

### 10.1 共通仕様

- 1行目はタイトル行、2行目以降がデータ行
- 同一コードのCSV内容で上書き
- エラー時は取込処理を停止

### 10.2 エラーコード

| コード | 名称 |
|--------|------|
| 100 | 桁あふれ |
| 200 | 数値以外 |
| 300 | 文字以外 |
| 400 | 規定値以外 |
| 500 | 必須 |
| 600 | 重複エラー |
| 700 | 存在エラー |

## 12. 非機能要件

| 分類 | 要件 |
|------|------|
| 可用性 | インターネット接続を前提、業務時間中に安定利用 |
| 性能 | 一般画面は実用的な応答時間、売上伝票約800行対応 |
| 同時実行 | 番号付番、請求締め、年次繰越は二重処理を防止 |
| トランザクション | ヘッダ・明細・残高・出力状態を一貫してコミット |
| 監査 | マスタ、伝票、締解除、年次繰越、権限変更の実行者・日時を記録 |
| バックアップ | サーバ保存データを定期バックアップ |
